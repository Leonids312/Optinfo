# Optinfo 推送内容要求

这是用户推送偏好的唯一正文记录。修改 Optinfo 的采集、筛选、写作或问答时读取本文件；服务器 Harness 也直接读取下方“生成规则”。以后收到新的内容要求，合并到相应条目，替换冲突的旧规则，再让代码、部署和实际样例与之保持一致，不另建重复的偏好清单。

## 生成规则

### 选择与范围

- 个人自用，中文每日简报，每天上海时间凌晨 04:00 生成，另提供重大事件。研究、产业、重大事件分别组织。
- 研究检索覆盖 Nature / Science 全系列，并扩展光学、材料领域核心期刊；光学、材料“一二区”采用中科院分区口径，不以 JCR 分区替代。按实际可核对的年度分区筛选，Nature / Science 系列单独纳入。检索范围广，实际推送仍按研究相关性和内容增量筛选，不因期刊名机械收录无关领域。
- 有方法比较、机理总结或研究脉络价值的综述可以推送，明确其综述性质，不把综述结论写成新完成的实验；一般性社论与目录不充数。
- 初始研究兴趣侧重软 X 射线与自由电子激光、EUV / X 射线辐照损伤、超快非平衡与电子晶格动力学、泵浦探测、时间分辨成像、MC / nTTM / MD 多尺度模拟，以及 Si / SiC / 金刚石、薄膜和界面。应用里明确保存的兴趣选择和生效日期优先于初始偏好；勾选引起的权重变化从次日生效。
- 企业覆盖芯片设计、晶圆制造、存储、半导体设备、光学元件、激光、光子器件、成像探测及工业应用，同时关注国内外企业。内容包括产品与工艺、扩产、并购、投资、组织调整和业务变化，不能让单一高频发稿公司占满分区。
- 企业资讯优先最近发生的事件；数量或公司覆盖不足时，由近及远补充尚未推送的历史事件。保留真实发布日期，不能把旧消息写成新发生。跨日期、跨入口对同一内容去重；同一事件有明确新进展时可以单独报道新进展。
- 其他重大事件包括显著市场波动、国家政策、科技监管和广泛影响的国际事件；一般性小新闻不充数。

### 内容与表达

- 直接讲清“发生了什么、如何实现、有哪些结果、为什么值得关注”。使用自然、简洁的中文，信息密度优先。
- 减少防御式、免责声明式叙事。不要主动评价新闻来源的可靠性，不反复写“仅据企业公告”“缺少第三方核验”“未获得独立评测”“不构成建议”“需谨慎看待”等套话，也不要在每节重复说明资料获取状态。
- 来源与日期放在对应的来源信息里。需要交代主体时自然写“公司发布/计划/测得”，无需反复强调“企业自称”。清楚区分计划与已完成事项、模拟与实验，不将条件性结果写成普遍结论。
- 评价写具体的技术优势、实验限制、适用条件、成本或业务影响。不能用“没有第三方验证”代替分析，也不必为每条新闻硬凑一段不足。没有可补充内容时简短收束。
- 减少套话不意味着编造数据或补猜事实。资料缺失影响核心结论时，在相应位置简短说明一次具体缺项；与主题无关的缺项直接略去。提问无法从现有材料回答时，直接指出还需要的具体信息，不展开免责声明。

### 论文讲解与问答

- 第一段概括成果，后续依次讲研究背景、研究方案、研究结果、总结（具体优势、不足及适用条件）。
- 研究结果必须配有支撑关键结论的原文图片，图注与选择说明为中文；可保留折叠的原文图注和来源。不能生成替代实验结果图。必要时展示包含该图的原文 PDF 页并明确页图形式。未取得必要正文与关键图时继续补充获取，不把残缺材料发布为完整解读。
- 摘要、正文、图注及问答中的公式均使用 LaTeX：行内 `\(...\)`，独立公式 `\[...\]`。等式、误差值、上下标和单位表达式也要正确排版，保留原文符号与数值。
- 同一推送的问题延续同一个会话；回答先解决问题，进一步解释机理和关联。推理使用自然的条件表达，不重复来源可靠性声明。

## 维护与核验

- 最近确认：2026-10-20；用户明确采用中科院分区。原分区平台已停止服务，实施时以可获得的 2025 版分区资料为核对基准；未逐刊核实的候选不能标成“已认证一二区”，也不能悄悄改用其他排行榜。
- 更新范围时同步检查出版方目录、可用采集入口、去重和实际入选样例；仅把名字写入列表不算接通来源。期刊年度与分区元数据留在采集配置，不写成每篇正文的说明。
- 本文件不包含学校账号、服务器凭据、API 密钥或开题报告原文。用户今后的内容偏好记在这里；访问配置留在私有配置文件中。
