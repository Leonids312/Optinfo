本版改进阅读时的切换速度，以及长文章中的问答与词条入口。

### 阅读缓存

- 今日简报和已浏览的历史查询保存在本机，返回页面时先显示已有内容。
- 保留各页面的筛选、搜索和阅读位置；缓存过期后在后台刷新，手动刷新可立即获取最新内容。
- 离线时仍可阅读已缓存的列表，提示当前缓存状态。北京时间跨日后不会把昨天的简报显示为今天。
- 修改服务器或访问令牌会切换缓存范围；聊天记录不写入本地持久缓存，继续由服务器按七天期限管理。

### 长文阅读

- 宽屏下正文与右侧探究面板分别滚动，继续探究、相关企业及词条不会随正文一起离开页面。
- 窄屏下提供固定的探究入口，可随时展开问答和词条，返回正文时保留阅读位置。

### 安装与更新

- Windows：完整解压 Windows ZIP，运行 `optinfo.exe`。
- Android：使用 APK 覆盖安装，保留原有应用数据与连接配置；采用与 v0.1.0 相同的发布签名。
- 继续使用原有 Tailscale 网络、Optinfo 地址及访问令牌，服务器无需迁移。

安装包由本标签的 GitHub Actions 测试、构建并发布；附带 SHA-256 校验文件和构建信息。未加入厂商通知服务。
