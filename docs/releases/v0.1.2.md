本版加入软件内版本检查，并包含 v0.1.1 的本地阅读缓存与固定探究面板。

### 软件内检查更新

- 启动或返回应用时，自动检查 Optinfo 的 GitHub 最新正式发布版；成功检查后六小时内不重复请求。
- 发现更新时显示提示，提供当前平台的安装包下载入口；连接设置中也可手动检查。
- 当前版本从安装包信息读取，更新检查不使用资讯服务的访问令牌，也不阻塞阅读。
- 检查失败可手动重试；自动检查采用短暂退避。下载后按系统提示安装，保留原有连接配置。

### 阅读改进

- 今日简报和历史查询保存在本机，切换时保留搜索、筛选与滚动位置；过期缓存先展示，再后台刷新。
- 宽屏右侧探究与词条面板独立滚动，窄屏有固定的探究入口。

### 安装

- Windows：完整解压 ZIP，退出旧版后运行新版 `optinfo.exe`。
- Android：下载 APK 覆盖安装，沿用原发布签名。
- 继续使用现有 Tailscale 连接与 Optinfo 服务地址。

安装包由本版本标签对应的 GitHub Actions 测试、构建并发布。附带 SHA-256 校验文件和构建信息。
