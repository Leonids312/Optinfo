本版优化论文证据与阅读体验。

### 论文图片与公式

- 从原文候选图中选择支撑研究结果的关键图，提供中文图注，并保留可展开的原文图注和来源。
- 论文解析保留原文中的数学信息，讲解和问答使用 LaTeX；客户端支持行内公式和独立公式，长公式可以横向滚动。
- 支持从可访问的原文 PDF 提取证据；无法可靠裁切时明确展示含关键图的原文整页。
- 图片保存在现有私人服务器，经身份验证读取。未获得完整证据的候选论文留待重试，避免发布成完整解读。
- 点击原图可打开缩放预览，方便检查关键细节。

### 桌面阅读设置

- 在首页或文章页打开“阅读设置”，字号可在 85%–150% 之间调整。
- 宽屏“探究与词条”栏可在 300–520 像素之间调整；窗口较小时会自动限制宽度，为正文保留空间。
- 设置即时生效并保存在本机，支持恢复默认值。

### 安装

- Windows：完整解压 ZIP，退出旧版后运行新版 `optinfo.exe`。
- Android：下载 APK 覆盖安装，沿用原发布签名。
- 保留原有 Tailscale 连接、收藏和会话。现有客户端也可通过软件内版本检查打开本版下载入口。

安装包由本版本标签对应的 GitHub Actions 测试、构建并发布，附带 SHA-256 校验文件和构建信息。
